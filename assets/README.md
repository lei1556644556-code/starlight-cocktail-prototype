# Asset Guide

这个文件夹存放正式网页资源，后续替换美术时优先改这里。

## 背景

- `bg/bar-backdrop.png`：游戏主背景。

## 酒杯

`drinks/` 下每张图都是透明 PNG，建议保持 256x256 或接近正方形。

- `level-01.png` 到 `level-14.png`：当前游戏实际使用的 14 级酒杯资源。
- `blue.png`、`orange.png`、`purple.png`、`red.png`、`pink.png`、`gold.png`：上一版 6 级资源备份。

只要保持文件名不变，替换图片后页面会自动使用新资源。

## UI

`ui/` 下是可复用界面素材：

- `hostess.png`：上方提示角色。
- `speech-bubble.png`：提示框素材。
- `panel-wide.png`：宽信息面板素材。
- `panel-tall.png`：右侧信息面板素材。
- `button-gem.png`：按钮素材。
- `progress-frame.png`：进度条框素材。
- `icon-row.png`：圆形图标素材备份。
