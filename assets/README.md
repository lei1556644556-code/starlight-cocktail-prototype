# Asset Guide

这个文件夹存放正式网页资源，后续替换美术时优先改这里。

## 背景

- `bg/bar-backdrop.png`：游戏主背景。

## 酒杯

`drinks/` 下每张图都是透明 PNG，建议保持 256x256 或接近正方形。

- `blue.png`
- `orange.png`
- `purple.png`
- `red.png`
- `pink.png`
- `gold.png`

只要保持文件名不变，替换图片后页面会自动使用新资源。

## 原始生成图

- `generated/bar-backdrop-generated.png`
- `generated/drink-spritesheet-generated.png`

这些是本次生成的原图备份，方便之后重新切图或回溯。
